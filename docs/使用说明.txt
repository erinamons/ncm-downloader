网易云音乐下载器 v1.4.0
================================

怎么用
------
双击「网易云下载器.exe」即可，不需要安装。

界面里的帮助（工具行问号图标，或按 F1）是截图 + 条目的形式：
上面是界面一览，下面按区域列每个按钮和控件，遇到不会用的先翻它。

这一版新增了什么
----------------
1. 本地音乐
   音源下拉框多了一项「本地」，列出下载目录里的音频文件；设置 →「本地音乐」
   可以再选一个放歌的文件夹（只读，不会改动里面的文件）。
   列表显示曲名 / 艺人 / 专辑 / 时长 / 大小，双击播放，右键可以定位文件、
   复制路径。扫描结果有索引，目录没变时切回来基本是秒开；加了新文件点
   底部的「重新扫描」。
   本地视图不显示下载队列，也没有下载按钮，搜索框直接当筛选器用；
   切回客户端 / 缓存，原来的队列和进度都会回来。

2. 拖拽播放
   音频文件或整个文件夹直接拖到窗口上，松手就播；文件夹会递归找里面的音频，
   不是音频的文件不会接受。拖进来的那批就是播放列表，上一首 / 下一首可用。

3. 关闭与托盘
   设置 →「关闭主面板」可选：最小化到系统托盘，或者直接退出（默认退出）。
   最小化按钮只是最小化到任务栏，不会进托盘；命令行窗口和开发者面板也不会
   跟着被最小化。托盘菜单重新做了一版：圆角深色、每项带图标、顶部显示
   当前曲目，退出项是红色的。

4. 紧凑模式的队列卡
   窄窗口底部是一张卡：标题和列表在同一个圆角框里，按窗口高度显示 3~5 行，
   全部完成后收成一行「N 首已完成」并给出清空入口。和上方结果表的接缝也改了，
   不再出现两个圆角互顶和 2px 双线。

5. 命令行帮助补全
   帮助里现在有完整的对照：28 条命令的中英写法、9 个设置键的中文名、
   各类参数的中文取值；每张命令卡底部也多了一行「中文写法」。
   另外修了「历史 清空」不生效和「取址 无损」不认中文音质两个小问题。

6. 开发者面板的下拉框
   之前弹出时会闪一下、圆角外还露出一个直角，现在和主窗口的下拉框一致。

播放不出声怎么办
----------------
打开开发者面板 → 状态页，看「无法直接播放」那一行：
  · 显示「否」= 这个文件本身能播，问题在音量/设备/文件损坏
  · 显示「是」= 这台机器的系统解码器放不了这个格式，两种选择：
      1) 到设置里勾选「兼容播放」，用内置 ffmpeg 转成 WAV 再播（默认关闭）
      2) 换一台标准版 Windows（N 版 / 精简版系统缺解码器）

兼容播放首次转换需要 1~3 秒，临时占用磁盘（约每分钟 10 MB），
播过的会缓存，同一首再播就很快。

所有东西都在这个文件夹里
------------------------
config.json     登录状态与设置（含账号凭据，别外传）
settings.ini    界面偏好：音质、并发、列宽、搜索历史
app.log         运行日志，反馈问题请附上它
crash.log       程序异常退出的记录（一般不存在）
play-cache\     播放缓存，设置里可清理
downloads\      默认下载目录，设置里可改到别处
diagnostics\    开发者面板导出的诊断包
local-index.json 本地音乐扫描索引（缓存，可删，会自动重建）
ffmpeg\         转码工具（转 mp3、兼容播放用），不要删
_internal\      程序依赖的库，不要动

拷走整个文件夹 = 带走全部状态；删掉文件夹 = 卸载干净。
不写注册表，不往 C 盘用户目录里塞东西。

反馈问题时给什么
----------------
打开开发者面板 → 复现一次问题 → 右下角「导出诊断包」，
把生成的 zip 发出来。里面有运行环境、配置（账号相关字段已打码）、
完整的操作步骤、错误记录和日志尾部，比截图有用得多。

常见问题
--------
1. 提示找不到 ffmpeg？
   确认 ffmpeg\binaries 下那个 100 MB 的 exe 还在。删了也能用，
   只是「转 mp3」和「兼容播放」不可用，下载其它格式不受影响。
   也可以在开发者面板「组件」页手动指定一个新的 ffmpeg.exe。

2. 想换新版？
   解压新版本，把 config.json 和 settings.ini 复制过去即可。
   下载目录里的 .ncm-index.db 是「已下载」记录，也一并保留。

3. 播放缓存占空间？
   设置里有「播放缓存 · 清理」，或者直接删 play-cache\。

4. 放进 Program Files 后设置存不住？
   那个位置通常没有写权限，程序会自动退回到
   %USERPROFILE%\.ncm-downloader。想保持便携就别放系统目录。

5. 界面突然变得很窄，按钮挤在一起？
   按 Ctrl+M 切回标准窗口。窗口宽度小于 780 会自动进紧凑模式。

6. 命令行下载和界面下载会重复吗？
   不会。两个入口共用同一份已下载记录（.ncm-index.db），
   音质和保存目录也跟随界面设置。

7. 切到「缓存」音源，列表里没有歌？
   设置 → 缓存目录 → 「缓存诊断」。它会说明目录对不对、找到几个缓存文件、
   有几个没下完或文件名不符合规则，底部还能直接打开缓存目录。
   多数情况是客户端缓存被清理过，或路径选到了上一级目录。

8. 点了右上角的 ×，程序不见了？
   设置 →「关闭主面板」决定：选「最小化到系统托盘」就收进托盘，下载和播放
   继续，点托盘图标打开；选「退出程序」则直接退出。
   最小化按钮始终只是最小化到任务栏，不会进托盘。

9. 想听电脑里已有的歌？
   音源下拉框选「本地」，列表就是下载目录里的文件；设置 →「本地音乐」
   可以再加一个放歌的文件夹（只读，不会改动里面的文件）。
   也可以把音频文件或整个文件夹直接拖进窗口，松手就开始播。
   本地视图不显示下载队列；切回客户端 / 缓存，原来的队列会回来。
