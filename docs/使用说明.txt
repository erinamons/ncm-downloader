网易云音乐下载器 v1.3.1
================================

怎么用
------
双击「网易云下载器.exe」即可，不需要安装。

界面里的帮助（工具行问号图标，或按 F1）有每个按钮的图解说明，
遇到播放失败、不知道某个按钮干嘛，先翻它。

这一版新增了什么
----------------
1. 不开界面也能下载
   程序目录下的 ncm-dl.bat 是命令行入口，不用启动界面就能搜索和下载。
   例：ncm-dl.bat dl 26093064
   加 --json 后输出可被别的程序解析，适合做自动化；所有子命令都支持，
   失败时会输出 {"ok": false, "error": "..."} 并以非零码退出。

2. 命令行窗口：Ctrl + 反引号键（1 左边那个键）随时打开
   也可以点状态栏右侧的终端图标，或托盘菜单「命令行…」。
   命令名、设置键、参数值都能写中文，例如：统计 / 音质 无损 / 设置 并发 4；
   Tab 补全、上下键翻历史，历史会留到下次启动。和开发者面板里的命令行页
   是同一份输出，不需要先开面板。不知道命令怎么写，点窗口右上角的问号
   （或按 F1）看帮助，里面有每条命令的语法和示例。

3. 出问题能查到原因了
   日志和异常从程序启动就开始记录，不用先打开开发者面板。
   上次如果没正常退出，下次打开面板会在「问题」页顶部用红条提示；
   点「打开崩溃现场」能看到当时的日志和调用栈，「复制现场」把上下文拷走。
   这些文件都在程序目录的 diagnostics 文件夹里，最多留 3 份。

4. 开发者面板（设置 → 开发者 → 开发者面板）
   出问题时用它定位。左边是流程时间线（搜索/缓存/下载/播放每一步做了什么、
   花了多久），右边是实时日志、问题列表、组件、命令行和环境信息。
   面板导航行最右边的 ? 是它自己的帮助（78 条），可以搜功能名或命令名。
   命令台里输入「模拟数据 全部」会造出一批假的搜索/队列/缓存，用来演练界面：
   不联网、不写文件，点下载或播放会被拦下，输入「模拟数据 清除」恢复。

5. 播放问题修好了
   以前缓存里的 m4a / flac 在部分电脑上必然播放失败，只能点重试走网络。
   原因是播放后端选错，现在默认用系统的 Media Foundation 解码器，四种格式
   都能直接播。实测放不出来的机器，可以到设置里开「兼容播放」。

播放不出声怎么办
----------------
打开开发者面板 → 状态页，看「无法直接播放」那一行：
  · 显示「否」= 这个文件本身能播，问题在音量/设备/文件损坏
  · 显示「是」= 这台机器的系统解码器放不了这个格式，两种选择：
      1) 到设置里勾选「兼容播放」，用内置 ffmpeg 转成 WAV 再播（默认关闭）
      2) 换一台标准版 Windows（N 版 / 精简版系统缺解码器）

兼容播放首次转换需要 1~3 秒，临时占用磁盘（约每分钟 10 MB），
播过的会缓存，同一首再播就很快。

所有东西都在这个文件夹里
------------------------
config.json     登录状态与设置（含账号凭据，别外传）
settings.ini    界面偏好：音质、并发、列宽、搜索历史
app.log         运行日志，反馈问题请附上它
crash.log       程序异常退出的记录（一般不存在）
play-cache\     播放缓存，设置里可清理
downloads\      默认下载目录，设置里可改到别处
diagnostics\    开发者面板导出的诊断包
ffmpeg\         转码工具（转 mp3、兼容播放用），不要删
_internal\      程序依赖的库，不要动

拷走整个文件夹 = 带走全部状态；删掉文件夹 = 卸载干净。
不写注册表，不往 C 盘用户目录里塞东西。

反馈问题时给什么
----------------
打开开发者面板 → 复现一次问题 → 右下角「导出诊断包」，
把生成的 zip 发出来。里面有运行环境、配置（账号相关字段已打码）、
完整的操作步骤、错误记录和日志尾部，比截图有用得多。

常见问题
--------
1. 提示找不到 ffmpeg？
   确认 ffmpeg\binaries 下那个 100 MB 的 exe 还在。删了也能用，
   只是「转 mp3」和「兼容播放」不可用，下载其它格式不受影响。
   也可以在开发者面板「组件」页手动指定一个新的 ffmpeg.exe。

2. 想换新版？
   解压新版本，把 config.json 和 settings.ini 复制过去即可。
   下载目录里的 .ncm-index.db 是「已下载」记录，也一并保留。

3. 播放缓存占空间？
   设置里有「播放缓存 · 清理」，或者直接删 play-cache\。

4. 放进 Program Files 后设置存不住？
   那个位置通常没有写权限，程序会自动退回到
   %USERPROFILE%\.ncm-downloader。想保持便携就别放系统目录。

5. 界面突然变得很窄，按钮挤在一起？
   按 Ctrl+M 切回标准窗口。窗口宽度小于 780 会自动进紧凑模式。

6. 命令行下载和界面下载会重复吗？
   不会。两个入口共用同一份已下载记录（.ncm-index.db），
   音质和保存目录也跟随界面设置。

7. 切到「缓存」音源，列表里没有歌？
   设置 → 缓存目录 → 「缓存诊断」。它会说明目录对不对、找到几个缓存文件、
   有几个没下完或文件名不符合规则，底部还能直接打开缓存目录。
   多数情况是客户端缓存被清理过，或路径选到了上一级目录。
